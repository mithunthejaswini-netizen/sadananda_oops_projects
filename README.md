# sadananda_oops_projects
python based oops oriented projects

Ror running the projects, please make sure you have python installed in your system.

To run any project, follow these steps:
1. Clone the repository using `git clone    
2. Navigate to the project directory using `cd <project_directory>`
3. Run the main file using `python <main_file.py>`
4. Paste the input as required by the project.
5. Finish with a newline or enter a key.
6. View the output displayed on the console.

For running the tests
1. Navigate to the project directory using `cd sadananda_oops_projects`
2. Run `pip install -r requirements.txt`
3. Run the test file using `pytest -q`
3. View the test results displayed on the console.
